# Швидкий старт

## ⚠️ Важливо: Версія Node.js

Slidev потребує **Node.js версії 18 або вище**.

## 🔧 Встановлення Node.js

### Використовуючи nvm (Рекомендовано):

```bash
# Встановити nvm (якщо ще не встановлено)
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash

# Перезавантажити термінал або виконати:
source ~/.zshrc  # або ~/.bashrc

# Встановити Node.js 18
nvm install 18
nvm use 18

# Перевірити версію
node --version  # має бути v18.x.x або вище
```

### Або встановити Node.js безпосередньо:

Завантажте з [https://nodejs.org/](https://nodejs.org/) (LTS версія)

## 🚀 Встановлення та запуск

### 1. Встановити залежності

```bash
npm install
```

### 2. Запустити презентацію

```bash
npm run dev
```

Або через npx (якщо є Node.js 18+):

```bash
npx @slidev/cli@latest
```

### 3. Відкрити в браузері

Презентація буде доступна за адресою **http://localhost:3030** (за замовчуванням)

## 📋 Структура проекту

## 🎮 Управління презентацією

- **←** / **→** - навігація між слайдами
- **Пробіл** - наступний слайд
- **F** - повноекранний режим
- **O** - режим огляду всіх слайдів
- **G** - перейти до слайду за номером

## 🛠️ Команди проекту

### Розробка та збірка
```bash
npm run dev              # Запуск в режимі розробки (localhost:3030)
npm run dev:port         # Запуск на порту 3001
npm run dev:host         # Запуск з зовнішнім доступом
npm run build            # Збірка статичної версії
npm run build:clean      # Очищення та збірка
npm run preview          # Перегляд зібраної версії
```

### Експорт
```bash
npm run export           # Експорт презентації
npm run export:pdf       # Експорт в PDF
npm run export:png       # Експорт в PNG
```

### Git управління
```bash
npm run git:status       # Перевірка статусу репозиторію
npm run git:commit       # Коміт всіх змін
npm run git:push         # Публікація гілки
npm run git:branch       # Створення нової гілки для слайду
npm run git:sync         # Синхронізація з віддаленим репозиторієм
npm run git:log          # Історія комітів
```

### Управління слайдами
```bash
npm run slide:add        # Додати новий слайд
npm run slide:backup     # Створити резервну копію
npm run slide:overview   # Згенерувати огляд слайдів
npm run slide:stats      # Статистика презентації
npm run slide:list       # Список всіх слайдів
```

### Документація
```bash
npm run docs:update      # Оновити документацію
npm run docs:check-links # Перевірити посилання
```

### Обслуговування
```bash
npm run setup            # Початкове налаштування проекту
npm run clean            # Очищення тимчасових файлів
npm run deps:check       # Перевірка оновлень залежностей
npm run deps:update      # Оновлення залежностей
```

### Перевірки якості
```bash
npm run check-node       # Перевірка версії Node.js
npm run check-deps       # Перевірка залежностей
npm run lint             # Перевірка Markdown стилю
npm run validate         # Повна валідація проекту
npm test                 # Запуск всіх перевірок
```

## 🎨 Генерація зображень з OpenAI API

### Налаштування OpenAI API

1. **Отримати API ключ** з [OpenAI Platform](https://platform.openai.com/api-keys)

2. **Створити .env файл**:
   ```bash
   cp .env.example .env
   ```

3. **Додати API ключ** до `.env`:
   ```
   OPENAI_API_KEY=sk-your-actual-api-key-here
   ```

### Генерація зображень

```bash
# Генерація одного зображення
npm run images:generate ai-concept images/slides/ai-concept.png

# Генерація всіх зображень для презентації
npm run images:batch
```

### Структура зображень

```
images/
├── slides/           # Зображення для слайдів
├── icons/            # Іконки та аватари
└── diagrams/         # Діаграми та схеми
```
