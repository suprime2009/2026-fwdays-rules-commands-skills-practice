# Структура проекту

## Загальна структура

```
.
├── doc/                    # Документація проекту
│   ├── README.md          # Головна документація
│   ├── getting-started.md # Швидкий старт
│   ├── slidev-guide.md    # Гайд по Slidev
│   ├── project-structure.md # Цей файл
│   └── PRD.md            # Product Requirements Document
├── scripts/               # Скрипти автоматизації
│   ├── git-workflow.sh   # Git команди
│   └── content-manager.sh # Управління контентом
├── slides.md              # Контент презентації (13 слайдів)
├── slidev.config.ts       # Конфігурація Slidev (TypeScript)
├── package.json           # Залежності та npm скрипти
├── package-lock.json      # Фіксовані версії залежностей
├── presentation.html      # Альтернативна HTML версія презентації
├── server.js              # Простий HTTP сервер для презентації
├── .gitignore            # Git ignore правила
├── .cursorrules          # Правила для Агентних IDE
└── README.md             # Головний README проекту
```

## Опис файлів

### Основні файли презентації

#### `slides.md`
- **Призначення**: Основний файл з контентом презентації
- **Формат**: Markdown з розширеннями Slidev
- **Структура**: 13 слайдів, розділених `---`
- **Особливості**: Використовує Slidev синтаксис (v-clicks, layouts, mermaid діаграми)
- **Редагування**: Основний файл для змін контенту презентації

#### `slidev.config.ts`
- **Призначення**: Конфігурація Slidev
- **Формат**: TypeScript
- **Налаштування**: 
  - Тема: default
  - Мова: українська (uk)
  - Шрифти: Inter (sans), Fira Code (mono)
  - Highlighter: shiki
- **Редагування**: Змінювати тільки при необхідності зміни налаштувань

#### `package.json`
- **Призначення**: Залежності та npm скрипти
- **Залежності**: 
  - `@slidev/cli`: ^0.49.0
  - `@slidev/theme-default`: *
- **Скрипти**:
  - `dev`: запуск в режимі розробки
  - `build`: побудова статичної версії
  - `export`: експорт в PDF

### Допоміжні файли

#### `presentation.html`
- **Призначення**: Альтернативна HTML версія презентації
- **Використання**: Для перегляду без Node.js/Slidev
- **Функціональність**: Повнофункціональна презентація з навігацією

#### `server.js`
- **Призначення**: Простий Node.js HTTP сервер
- **Використання**: Для локального запуску HTML презентації
- **Порт**: 8080 (за замовчуванням)

### Документація

#### `doc/` - папка з документацією
- **doc/README.md**: Головна документація проекту
- **doc/getting-started.md**: Інструкція з швидкого старту
- **doc/slidev-guide.md**: Детальний гайд по Slidev
- **doc/project-structure.md**: Опис структури проекту (цей файл)
- **doc/PRD.md**: Product Requirements Document

#### `scripts/` - папка зі скриптами автоматизації
- **scripts/git-workflow.sh**: Команди для роботи з Git
- **scripts/content-manager.sh**: Управління контентом презентації

#### `README.md`
- **Призначення**: Головний README в корені проекту
- **Зміст**: Короткий опис проекту та посилання на документацію

### Конфігураційні файли

#### `.gitignore`
- **Призначення**: Правила для Git
- **Ігнорує**: node_modules, build артефакти, логи, IDE файли

#### `.cursorrules`
- **Призначення**: Правила для Агентних IDE (агента ШІ)
- **Зміст**: Посилання на документацію та технічні вимоги

## Організація коду

### Принципи

1. **Документація в `doc/`**: Вся документація зібрана в одній папці
2. **DRY принцип**: Правила посилаються на документацію, не дублюють її
3. **Чіткі назви**: Файли мають зрозумілі назви, що відображають їх призначення
4. **Розділення відповідальності**: 
   - `slides.md` - контент
   - `slidev.config.ts` - конфігурація
   - `doc/` - документація

## Робота з проектом

### Додавання нового слайду

1. Відкрити `slides.md`
2. Додати новий слайд після `---`
3. Використовувати Slidev синтаксис
4. Перевірити в браузері через `npm run dev`

### Зміна конфігурації

1. Відкрити `slidev.config.ts`
2. Змінити потрібні параметри
3. Перезапустити `npm run dev`

### Оновлення документації

1. Відкрити відповідний файл в `doc/`
2. Внести зміни
3. Переконатися, що посилання актуальні

## Технічні вимоги

- **Node.js**: 18.0.0 або вище (обов'язково)
- **npm**: Версія, сумісна з Node.js 18+
- **Операційна система**: Будь-яка з підтримкою Node.js

## Залежності

Всі залежності вказані в `package.json`. Основні:

- `@slidev/cli`: CLI інструмент для Slidev
- `@slidev/theme-default`: Тема за замовчуванням

Детальніше про залежності та їх версії - в `package.json` та `package-lock.json`.
