# Гайд по Slidev

## Що це таке

Ця презентація створена за допомогою [Slidev](https://sli.dev/) - інструменту для створення презентацій на основі Markdown з підтримкою інтерактивних елементів.

## Як запустити

### Передумови

- Node.js версії 18 або вище
- npm або yarn

### Встановлення залежностей

```bash
npm install
```

### Запуск в режимі розробки

```bash
npm run dev
```

або

```bash
npx slidev
```

Презентація буде доступна за адресою `http://localhost:3030`

### Побудова для продакшну

```bash
npm run build
```

### Експорт в PDF

```bash
npm run export
```

## Структура презентації

- **Вступ** - що таке Агентні IDE
- **Основні правила** - як ефективно працювати з AI-помічниками
- **Команди та інструменти** - основні команди для роботи
- **Навички** - які навички потрібні для ефективної роботи
- **Найкращі практики** - рекомендації та приклади
- **Висновки** - підсумки та перспективи

## Особливості презентації

- Використовує українську мову
- Містить інтерактивні елементи (v-clicks)
- Включає діаграми Mermaid
- Адаптивний дизайн
- Темна/світла тема

## Налаштування

Конфігурація знаходиться у файлі `slidev.config.ts`. Ви можете змінити:

- Тему оформлення
- Шрифти
- Колірну схему
- Інші параметри

## Розробка

Для редагування презентації змінюйте файл `slides.md`. Зміни автоматично відобразяться в браузері при запуску `npm run dev`.
