# Документація проекту: Презентація Slidev

Проект презентації на тему "Правила, команди та навички для Агентних IDE", створений за допомогою [Slidev](https://sli.dev/).

## Швидкий старт

Для швидкого початку роботи з проектом, дивіться [getting-started.md](./getting-started.md).

## Документація

- **[PRD (Product Requirements Document)](./PRD.md)** - вимоги до воркшопу та детальний план розробки
- **[Швидкий старт](./getting-started.md)** - як встановити та запустити презентацію
- **[Гайд по Slidev](./slidev-guide.md)** - детальна інформація про використання Slidev
- **[Структура проекту](./project-structure.md)** - опис структури файлів та організації проекту

## Основна інформація

### Технічний стек

- **Slidev** 0.49.0 - фреймворк для презентацій на основі Markdown
- **TypeScript** - для конфігурації (`slidev.config.ts`)
- **Node.js 18+** - обов'язкова вимога
- **npm** - менеджер пакетів

### Основні файли

- `slides.md` - контент презентації (15 слайдів)
- `slidev.config.ts` - конфігурація Slidev
- `package.json` - залежності та npm скрипти
- `presentation.html` - альтернативна HTML версія презентації

### Команди

```bash
npm run dev      # Запуск в режимі розробки
npm run build    # Побудова статичної версії
npm run export   # Експорт в PDF
```

Детальніше про команди та налаштування - в [getting-started.md](./getting-started.md).

## Структура презентації

Презентація містить 27 слайдів, що охоплюють:

- Вступ в Агентні IDE
- Основні правила роботи з AI-помічниками
- Команди та інструменти
- Навички та найкращі практики
- Приклади та висновки

Повний список слайдів - в [slidev-guide.md](./slidev-guide.md).
